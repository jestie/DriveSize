Features

Everything TreeSize does.
Prettier.

A proper disk utility in a single folder. Double-click and it opens in your browser.

🍩

Donut charts everywhere

Every drive and folder broken down by subfolder and file type. Hover for detail, click a slice to dive in.

⚡

Seriously fast

Multi-threaded native scanning: millions of files in under a minute, with live progress as it goes.

🧹

Smart cleanup

Flags temp folders, caches, old installers, logs and forgotten venvs as Safe or Review, with the reason why.

📂

Browse like Explorer

Breadcrumbs, sortable columns, size bars, filters, and a jump straight to the folder in Windows Explorer.

👯

Duplicate finder

Spots big files that exist twice, so you can keep one and reclaim the rest.

🏆

Largest files

The top 1,000 space hogs on the drive, one click from deletion. Plus a breakdown by extension.

How it works

Three steps. Zero setup.

All you need is Python 3, which you probably already have.

Grab it

Download the ZIP or git clone the repo anywhere you like.

Launch it

Windows: double-click DriveSize.bat. Linux/WSL: run ./drivesize.sh.

Clean up

Pick a drive, watch it map, tick the junk and send it to the Recycle Bin.

Safety first

Deleting, without the fear.

✓
Recycle Bin by defaultChanged your mind? Restore it. Permanent delete is opt-in.
✓
System areas are lockedWindows, Program Files, drive roots and page files are refused, every time.
✓
Never leaves your machineRuns on 127.0.0.1 with a per-session token. No cloud, no telemetry, no accounts.
